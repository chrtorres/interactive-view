# Suspension example

Run `node --test test-dynamics.mjs` from this directory. The example models a one-axis rigid plate with a moving support. Pass mass in kg, effective length in m, spring in N·m/rad, damping in N·m·s/rad, angular stops in radians, and a unit vector in the horizontal swing direction to `makeJoint`. Acceleration is in m/s². A 120 Hz semi-implicit step integrates gravity, projected support acceleration, spring and damping. The geometric stops are one-dimensional contact approximations. Example masses and stop settings are synthetic.

In a browser pane, resolve caller-declared glTF node names after load and retain each rest quaternion. Convert your documented world hinge axis to the pivot's rest-local frame. Compose the solver angle with the rest quaternion each frame. Apply offsets to independent attachment pivots instead of modifying the reviewed mesh. Drive the solver with an accumulator, bound frame catch-up, and reset the accumulator on pause or visibility changes. Recompute pose, readouts and any load arrow synchronously on reset. Reset or load failure should have an observable state.

Use a same-origin companion pane with the review workspace lifecycle. Include a source note for parameter assumptions and explain the difference between angular stops and mesh collision. Prove rotation on an actual GLB node and compare settled pixels on desktop and narrow touch viewports. Exercise pause between frames, reset before the next frame, and no unexpected external requests. This example exposes the solver and tests. The product supplies the renderer adapter, GLB and pointer controls.
